# Plan V6 — Cumplimiento WCAG 2.1 AA según `plan_de_desarrollo_frontend.md`

**Fecha:** 06-oct-2026
**Objetivo:** Adaptación del plan del frontend (sección 4–6) al stack actual (Svelte 4 + Vite 5 + D3 + CSS con variables), alcanzando WCAG 2.1 Nivel AA.

> Nota: El plan original propone Next.js + Tailwind + Radix UI + React Hook Form. El proyecto ya está consolidado en Svelte 4 + Vite 5 + D3 + CSS con variables, por lo que se traduce cada requisito al stack actual sin migrar.

## Fases de ejecución

### Fase 1 — Foco y teclado (2.4.7, 2.1.1)
1. Añadir `:focus-visible` a todos los botones con estilos scoped.
2. Gestión de foco en Metodología: al abrir, foco a `#metodologia-title` (`tabindex="-1"`); al cerrar, devolver foco al botón "Metodología"; tecla `Esc` cierra.

### Fase 2 — Contraste y reflujo (1.4.3, 1.4.10, 1.4.11)
3. Auditoría de contraste en ambos temas (muted, badges, KPI, asientos); corregir a ≥4.5:1 / 3:1.
4. `.kpi-grid` → `minmax(min(100%, 280px), 1fr)`; verificar sin scroll horizontal a 320px y zoom 400%.

### Fase 3 — Semántica y estados (4.1.3, F7)
5. Quitar emojis de Metodología (texto plano o SVG); ocultar ✕ a lectores (`aria-hidden="true"`).
6. Reemplazar `alert()` de copiado por mensaje en región `aria-live`.

### Fase 4 — Verificación y documentación
7. `npm test` + `npm run build` (sin warnings, `dist/` < 1 MB).
8. Lighthouse accesibilidad > 95 en ambos temas; registrar en `Historial/PRUEBAS_ESCRITORIO.md`.
