# Plan V3 — Tema claro/oscuro, logo INE 2026 y limpieza de UI

**Fecha:** 05-oct-2026

## Diagnóstico (investigación)

- El frontend tiene menciones explícitas a "Equipo de 2 Personas" y "HACKATHON INE • RETO 3" (badge del header y footer) y en el PNG de la tarjeta.
- Uso extensivo de emojis en componentes (📊 💡 ⚠️ ℹ️ 🔒 📱 💬 🗳️ etc.).
- El apartado **Metodología es obligatorio** (requisito F7 del README/CHECKLIST): no se elimina, se corrige (sin emojis, estilos coherentes en ambos temas, marcadores CSS en lugar de ✅/❌).
- Existe logo oficial en `images/logo_ine2026.png`.

## Plan

### 1. Integración del logo oficial
- Mover `images/logo_ine2026.png` → `public/images/logo_ine2026.png`.
- Header: sustituir `🗳️ INE` por `<img src="/images/logo_ine2026.png" alt="INE 2026">`.
- Footer y tarjeta PNG: usar el logo u omitir texto redundante.

### 2. Toggle de tema Claro/Oscuro
- Botón en el header con icono SVG (sol/luna), alterna `data-theme` en `<html>`.
- `global.css`: variables para ambos temas:
  - Oscuro (actual, `:root`).
  - Claro INE: `#F8F9FA` fondo, superficies `#FFFFFF`, texto `#1A2238` (prompt de sistema).
- Default según `prefers-color-scheme`; preferencia en memoria (sin localStorage, por privacidad).

### 3. Eliminación de emojis
- `App.svelte`: `🗳️` → logo; badge "HACKATHON INE • RETO 3" eliminado.
- `Comparacion.svelte`: 📊/💡 → texto o SVG.
- `LineaDeVida.svelte`: 📊/📋/ℹ️ → texto con SVG.
- `Metodologia.svelte`: emojis en headings/listas y `content: '✅'/'❌'` → viñetas CSS.
- `Selector.svelte`: `⚠️` → "Aviso:".
- `Tarjeta.svelte`: emojis de "Cómo compartir" → texto; footer del PNG sin "Hackathon/Reto 3".
- Botones sociales: 💬📷𝕏 → SVG inline simples.

### 4. Titulares prohibidos
- Sin "Equipo de 2 personas" ni "Reto #3" en UI, footer ni PNG.

### 5. Corrección visual de Metodología
- Headings y bloques con variables de tema; `.definition`/`.warning` coherentes en ambos temas.
- Link "Reporte de Validación" con destino funcional.

### 6. Verificación
- `npm run build` sin warnings, `npm test` en verde, revisión visual de ambos temas.
