# Plan V4.6 — Ajuste de layout, iconos sociales y nav/progreso

**Fecha:** 05-oct-2026

## Diagnóstico

1. **Desfase al ingresar año/estado**: el bloque de `Tarjeta.svelte` usa un canvas 1080×1350 muy alto dentro de `.additional-sections` apilado, generando saltos de altura.
2. **Iconos sociales no visibles**: los SVG dependen de `currentColor` heredado del `button`; en ciertos temas/browsers no contrasta.
3. **Footer con espacio debajo** al mostrar datos: `main` no tiene `flex:1` efectivo para empujar al footer cuando aparecen las secciones de datos.
4. **Top-bar al hacer scroll**: revisar z-index y que la barra de progreso de lectura no desaparezca.

## Plan

### 1. Distribución de secciones de datos
- Reemplazar `.additional-sections` apilada por una grilla: `Comparacion` y `SillaVacia` en dos columnas, `Tarjeta` abajo a ancho completo.
- Acotar el canvas de `Tarjeta` (prop. 4:5, `max-width:360px` en el wrapper) y uniformizar paddings.

### 2. Iconos sociales (X, Facebook, Instagram, WhatsApp)
- Cuatro botones con SVG inline simple, todos con `fill/stroke="currentColor"`.
- `.share-box .btn-social { color: var(--color-text) }` para forzar contraste en ambos temas.
- Íconos: X, Facebook, Instagram, WhatsApp.

### 3. Footer pegado
- `main.main-content { flex: 1 0 auto; }` y `.app-footer { margin-top: 0; flex-shrink: 0; }`.

### 4. Barra de navegación/progreso
- Top-bar `position: fixed; z-index: 1100`.
- Franja de progreso de lectura en el borde inferior de la top-bar (franja estrecha con gradiente primario que se llena con `window.scrollY`).

### 5. Verificación
- `npm run build` sin warnings, `npm test` en verde.
- Probar: ingresar año+estado, revisar que no hay desfase, iconos visibles en ambos temas, footer pegado, progreso al hacer scroll.
